# PyPreviewHost2

*By default PowerToys just uses Monaco in some files, that is limited by the app itself. If you want to use this patch with files which are not included you shall change the .reg shellex*



Universal previewer (text, code, configuration, binaries) for the PowerToys preview pane.
C# / WPF / .NET Framework 4.8 / x64. Only dependency: AvalonEdit 6.3.1.120 (MIT license).

## Build
    msbuild PyPreviewHost2.csproj -restore -p:Configuration=Release -p:Platform=x64
Output: bin\x64\Release\PyPreviewHost2.exe

## Launch contract (unchanged from the original)
    PyPreviewHost2.exe <file-path> <parent-HWND-in-hex-without-0x>
Exit codes: 1 = missing arguments, 2 = invalid HWND, 99 = fatal error
(details in %TEMP%\PyPreviewHost2-error.txt).
Added: the child resizes to the parent's client area (polling every 100 ms) and the process terminates
if the parent disappears. Can be disabled with autoResizeToParent=false.

## Shortcuts / context menu
Ctrl+H text<->hex · Ctrl+W word wrap (visual) · Ctrl+L line numbers · Ctrl+ +/-/0 font size
Hex: drag to select, Ctrl+C copies bytes (or ASCII if started in the ASCII column),
menu: copy hex / ASCII / dump / offset, go to start/end, bytes per row (8/16/24/32).

## Optional configuration
%LOCALAPPDATA%\PyPreviewHost2\settings.ini: wordWrap, lineNumbers, fontSize, bytesPerRow,
maxTextBytes (64 KiB–32 MiB, default 8 MiB), autoResizeToParent, fontFamily.

## Encoding detection (deterministic)
BOM (UTF-8/16/32) -> UTF-16 without BOM by NUL pattern (marked [guess]) -> strict UTF-8
(or mostly valid) -> system ANSI code page (marked [guess]).
NULs or many control characters = binary (never decoded as text).
Files > maxTextBytes: the beginning is shown, cut at a line boundary, marked PARTIAL.
Highlighting disabled for text > 2 M characters or lines > 20,000 characters.

## Formats
- Text/code/config: see catalog in Core.cs (FormatCatalog); ~45 lexical (non-semantic) definitions.
- Specialized readers (metadata only, nothing is executed or extracted): PE, ZIP/JAR/DOCX…, ELF (header),
  SQLite (header only, no schemas), Java class (name/version), gzip.
- Hex only (no parser): PDF, 7z, RAR, TAR, WASM, pyc, .obj/.lib/.pdb, etc.
- To add a reader: implement IPreviewReader and register it in ReaderRegistry.CreateDefault().

## Known limitations
- Lexical highlighting: HTML does not highlight embedded JS/CSS; JS does not distinguish regex literals; .m is treated as MATLAB.
- Scrollbars use the default WPF style (not dark).
- Verification status: tested and working on PowerToys W11 (named version)
